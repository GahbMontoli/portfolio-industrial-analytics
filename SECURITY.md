# Segurança e dados

Este repositório é um laboratório público. Não envie:

- credenciais, tokens, cookies ou strings de conexão;
- nomes de clientes, empresas, pessoas ou equipamentos reais;
- dados de produção, manutenção, telemetria ou localização não anonimizados;
- arquivos PBIX com cache de dados privados;
- caminhos de rede, IPs ou detalhes de arquitetura corporativa.

Os exemplos públicos devem ser sintéticos ou provenientes de fontes abertas com
licença e proveniência registradas. Problemas de segurança podem ser comunicados
privadamente ao mantenedor pelo recurso de security advisory do GitHub.
